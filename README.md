This visual shows the at the moment most popular python-repositories on GitHub. The data I extraced and added in list is 
from a api-reqeust-answer. In this answer were informations about each python-repository. Later I only took the 
repositories with the most stargazers. I extraced information about each repository such as description and owner and 
put it into the visual as an hover name. I also put the links to these repositories on the x-axis below the bars with 
the amount of stargazers. Each link is marked in blue with their project-name. With clicking on it you'll get to the 
repository. 

The data for this visual is from the github-api-url that you can find in the code. The idea for this visual is from 
an excercise from the book "python crashcourse - eric matthes".
